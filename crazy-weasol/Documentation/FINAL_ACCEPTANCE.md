# Final Acceptance Contract

## Required path
New Game → Cinematic → Move → Fight → Explore → Core discovery → Gravity Fracture → Mutation Wave → Experimental Guardian → Escape → Save → Quit → Load → Continue.

## Rule
Documentation/configuration does not constitute runtime proof. Acceptance requires executable evidence from the actual Unity project/build.

## Blockers
P0 defects, save corruption, progression blockers, boss soft-locks, unrecoverable crashes, critical performance failures, broken builds, or missing required content.
